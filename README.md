# Abdelbassit Abed Meraim Portfolio

Personal portfolio built with Next.js to showcase experience, technical skills, certifications, featured analytics projects, and contact information.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel Analytics
- Google Analytics 4

## Featured Work

- Customer Churn Analysis - Power BI Dashboard
- HR Analytics - Employee Attrition Dashboard
- Food & Beverage - Marketing Analytics Platform

## Local Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Project Structure

- `app/` - Next.js app router files
- `components/` - portfolio sections and UI logic
- `public/` - static assets such as images and CV

## Deployment

This project is set up to deploy on Vercel from the `main` branch.
